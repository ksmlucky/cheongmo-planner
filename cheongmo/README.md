# 청모

서로 아는 사람끼리 자연스러운 청첩장 모임을 만드는 개인용 플래너.

- 사람, 알게 된 곳 복수 선택, 초대 결정, 관계 메모 관리
- IBM, EY한영, 화곡고등학교 등 구체적인 회사·학교·모임 이름을 목록으로 저장하고 재사용
- 알게 된 곳 이름 변경 시 연결된 사람에게 일괄 반영, 기존 그룹·백업 자동 호환
- 양방향 아는 사이 / 따로 만나기 관계 관리
- 시작할 사람과 초대 인원에 따른 추천, 수동 조합, 관계도
- 모임 날짜·장소·메모, 만남 완료, 개인 메모를 제외한 안내문 복사
- 사람별 받은 청첩장, 내가 낸 축의금(KRW), 상대 결혼식 날짜 및 메모
- 명시적으로 입력한 관계만 추천에 사용. 축의금 기록은 추천에 영향을 주지 않음
- 이 브라우저 localStorage에 저장. 기기 간 자동 동기화 없음
- JSON 전체 백업/검증된 복원. 미기록 금액(null)과 0원 구분
- 가상의 예시 명단 제공. 내 명단 시작하기로 초기화

## 실행

Node.js 20 이상에서 별도 의존성 없이 실행합니다.

```sh
npm start
npm test
```

로컬 주소: http://127.0.0.1:4173

배포 대상은 `dist/`의 정적 파일입니다. 로컬의 `.openai/hosting.json`은 배포 도구용 설정이므로 공개 저장소에서는 제외합니다. 로컬 실행에는 필요하지 않습니다. 실제 명단은 저장소나 배포 파일에 포함되지 않고 사용자 브라우저에 저장됩니다.

날짜 입력과 표시 기준은 대한민국(Asia/Seoul)입니다. 안내문 복사는 전송 기능이 아닙니다. 사용자가 원하는 곳에 직접 붙여넣습니다.

## 설치 없이 사용

상위 폴더의 `청모.html`을 브라우저에서 열면 됩니다. CSS와 JavaScript가 모두 포함되어 인터넷 연결 없이도 작동합니다. 다시 만들려면 `node build-standalone.mjs`를 실행하세요.

로컬 파일과 웹 주소의 저장 영역은 별개입니다. 파일 위치나 브라우저를 바꾸기 전에 JSON 백업을 내려받고, 새 위치에서 복원하세요.
